# Employee Attrition Prediction

## Project Overview
This project predicts employee attrition using machine learning.

## Machine Learning Model
Tuned Random Forest Classifier.

## Web Application
Streamlit.

## Run the Application
1. Install the required libraries:
   pip install -r requirements.txt

2. Start the application:
   streamlit run app.py

## Model Evaluation
The selected tuned Random Forest achieved:
- Accuracy: 80.27%
- Precision for Attrition = Yes: 42.03%
- Recall for Attrition = Yes: 61.70%
- F1-score for Attrition = Yes: 50.00%

## Disclaimer
Predictions are estimates and should not be used as the sole basis
for employment decisions.
